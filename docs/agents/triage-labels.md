# 트리아지 라벨

스킬들은 다섯 가지 정규 트리아지 역할로 말한다. 이 파일은 그 역할을 이 리포의 이슈 트래커가
실제로 쓰는 라벨 문자열에 대응시킨다.

| mattpocock/skills의 라벨 | 우리 트래커의 라벨 | 의미 |
| ------------------------ | ------------------ | ---- |
| `needs-triage`           | `needs-triage`     | 관리자가 이 이슈를 판단해야 함 |
| `needs-info`             | `needs-info`       | 제보자의 추가 정보를 기다리는 중 |
| `ready-for-agent`        | `ready-for-agent`  | 명세가 충분해 에이전트가 자율 처리 가능 |
| `ready-for-human`        | `ready-for-human`  | 사람이 직접 구현해야 함 |
| `wontfix`                | `wontfix`          | 처리하지 않기로 함 |

스킬이 역할을 언급하면(예: "에이전트 처리 가능 라벨을 붙여라") 이 표의 오른쪽 열에 있는 실제
라벨 문자열을 쓴다.

실제로 쓰는 어휘가 다르면 오른쪽 열만 고치면 된다.
